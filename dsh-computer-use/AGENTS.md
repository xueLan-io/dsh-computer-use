# dsh-computer-use Source

This nested directory is the actual `dsh-computer-use` package source.

- Edit TypeScript/JavaScript and the Windows Node-API provider (`native/`)
  here.
- The active profile link is
  `D:\DSH_HOME\profiles\web\node_modules\dsh-computer-use`.
- The package is loaded by DSH from the web profile; it is not part of
  `D:\DSH_WORKSPACE\desktop\DSH_APP`.
- Do not edit the profile's resolved `node_modules` junction directly.
- Validate Windows native dependencies and package scripts from this
  directory. Do not add machine-local credentials, screenshots, or session
  data to the repository.
