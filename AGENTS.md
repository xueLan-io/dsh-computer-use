# Computer Use Plugin Repository

This directory is the repository wrapper for the computer-use plugin.

- Plugin source is under `dsh-computer-use\`.
- Runtime source link:
  `D:\DSH_HOME\profiles\web\node_modules\dsh-computer-use`.
- Do not search `D:\DSH_HOME` for source implementation; edit the nested
  `dsh-computer-use` repository instead.
- Do not modify the official engine checkout at `D:\DSH`.
- Windows UI Automation and native desktop automation belong to this plugin
  (`dsh-computer-use/native`), not to the desktop shell under
  `D:\DSH_WORKSPACE\desktop\DSH_APP`.
- Keep screenshots, credentials, sessions, and runtime logs outside the
  repository.
